# Air Quality Dashboard

## Cara menjalankan

1. Simpan `app.py`, `requirements.txt`, dan `Data AQI.json` pada folder yang sama.
2. Buka terminal pada folder tersebut.
3. Install dependency:
   pip install -r requirements.txt
4. Jalankan:
   streamlit run app.py

Dashboard mencakup KPI AQI, tren harian, profil polutan, korelasi, scatter plot,
perbandingan AQI vs AQI-IN, insight otomatis, filter tanggal, dan tabel data.
